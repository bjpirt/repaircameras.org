Contributing

All contributions are welcome! Whether you've found a service manual, want to share a repair tutorial, or just spotted a typo — we'd love your help building this free resource for camera repairers.

How to contribute

We have an online editor that makes it easy to add or edit content without any coding knowledge.

  • Click the Edit this page button on any camera or tutorial page (or go straight to the editor)
  • Sign in with a free GitHub account
  • Make your edits using the online editor
  • Submit your changes for review
  • A site maintainer will check everything over and your changes go live

That's it — no coding required.

What you can contribute

  • Camera pages — add a new camera with links to service manuals, repair guides, and useful resources
  • Repair tutorials — write step-by-step guides with annotated photos to help others fix their cameras
  • Service manuals — upload scans of service or user manuals as PDFs
  • Links to resources — YouTube videos, blog posts, or other repair guides from around the web
  • Improvements — fix typos, add troubleshooting tips, or expand existing pages

For developers

The site is open source. If you prefer working with code directly, you can also contribute via a pull request on GitHub.
